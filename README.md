# DeadlockNews — веб-застосунок для iPhone

Сайт, який встановлюється на iPhone як програма: власна іконка, запуск на весь екран, робота без інтернету після першого відкриття.

## Що всередині
```
index.html            — увесь застосунок (екрани, стилі, логіка, контент)
manifest.webmanifest  — назва, іконки, повноекранний режим
sw.js                 — сервіс-воркер (офлайн-кеш)
icons/                — іконки 180, 192 і 512 px
```

## 1. Опублікувати на GitHub Pages
1. Створіть публічний репозиторій, наприклад `deadlocknews`.
2. Завантажте **вміст** цієї папки в корінь репозиторію (Add file → Upload files).
3. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/ (root)` → Save.
4. Через 1–2 хвилини сайт з’явиться за адресою `https://<ваш-логін>.github.io/deadlocknews/`.

## 2. Встановити на iPhone
1. Відкрийте адресу сайту в **Safari**.
2. Натисніть «Поділитися» (квадрат зі стрілкою).
3. Оберіть «На початковий екран» → «Додати».

Іконка DeadlockNews з’явиться на робочому столі, а застосунок відкриватиметься без панелей браузера.

## Що працює
- Нижнє меню: Новини, Поради, Аналіз, Герої, Профіль.
- Новини: категорії, пошук, стаття з джерелами, закладки, копіювання посилання.
- Поради: перемикач «Новачок / Ветеран», розділи, «Порада дня» з перемиканням.
- Аналіз: демо-матч, кожна помилка веде до потрібного розділу порад.
- Герої: 44 герої, пошук, фільтри за роллю, «Нові», «Улюблені»; картка героя з останніми змінами.
- Фото героїв: «Додати фото» в картці героя. Будь-яке зображення обрізається до квадрата й отримує однаковий латунний дуотон у восьмикутній рамці.
- Профіль: графік, збережені статті, чорно-білий режим, рівень, інструкція встановлення, скидання.

Закладки, улюблені, фото та налаштування зберігаються на телефоні (localStorage).
